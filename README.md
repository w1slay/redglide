# RedGlide

Site statique de comparateur créé pour **RedGlide — créé par w1slay**.

## Fichiers
- `index.html` : accueil + BUZZ DU MOMENT
- `search.html` : sélection de deux trottinettes
- `compare.html` : comparateur détaillé
- `velo.html` : catégorie vélos électriques
- `voiture.html` : catégorie voitures
- `styles.css` : design
- `app.js` : fonctionnement
- `data.js` : **toutes les données facilement modifiables**

## Modifier les modèles
Ouvre `data.js` et modifie les objets `SCOOTERS`, `VELOS` et `CARS`.

## Lancer
Double-clique sur `index.html` ou utilise un petit serveur local.

## Contact
Le contact RedGlide est `redglidebike@gmail.com`. Il est accessible depuis le menu du site.

## Publicité personnalisable
Le bloc publicitaire apparaît automatiquement en bas de chaque comparaison. Pour le personnaliser, ouvre `app.js` et modifie `AD_CONFIG` : titre, texte, image, lien, bouton et activation/désactivation.

## Nom de domaine
Le site est un site statique et peut être publié sur un domaine personnalisé en `.fr`, `.com`, `.net`, etc. Il faut acheter/enregistrer le domaine auprès d’un registrar puis le relier à l’hébergement choisi. Le code n’achète pas le domaine automatiquement.

## Important
Les données techniques sont des données de départ et peuvent varier selon les versions, marchés et configurations. Vérifier la fiche constructeur avant publication commerciale.
